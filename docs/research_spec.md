# PB-ROE 研究规格

## 1. 研究问题

项目回答五个递进问题：

1. 原研报 PB、ROE 与综合得分策略能否得到方向性复现？
2. 在历史成分股、公告时点和可交易性约束下，PB-ROE 是否仍有效？
3. 收益是否由行业、市值等暴露解释？
4. 扩展因子是否相对 PB-ROE 提供增量？
5. 预测信号在成本和风险约束后是否仍可交易？

本阶段只实现问题 1-3 所需的工程和评价能力；LightGBM 与组合优化留给后续提交。

## 2. 实验分层

### 股票池冻结

原研报复现层与现代改进层的主股票池均固定为调仓日有效的沪深 300 历史成分股（`CSI300`）。中证 800 和其他股票池均不进入正式实验、模型训练、组合优化或主结果；稳健性检验仅在沪深 300 历史成分股范围内进行。

| ID | 实验 | 用途 |
|---|---|---|
| R0 | 沪深 300 | 复现层基准 |
| R1 | ROE 分组 | 原文质量效应 |
| R2 | PB 分组 | 原文价值效应 |
| R3 | PB_ROE 综合得分分组 | 原文综合策略 |
| R4 | PB_ROE 行业内选股 | 原文行业调整策略 |
| M0 | 沪深 300 | 现代层基准 |
| M1 | 月频 PB-ROE | 现代可交易基准 |
| M2 | 因子分层与 Top-Bottom | 预测能力评价 |

## 3. 原研报复现口径

- 股票池：调仓日有效的沪深 300 成分股；
- 研究期：2005 年一季度至 2011-03-25；
- 调仓日：每年 04-30、08-31、10-31；非交易日使用此前最近交易日；
- 信号：调仓日可获得的最新一期财务报告；
- 成交：调仓日收盘价；
- 权重：默认等权；行业版本分别使用全组合等权和基准行业权重；
- 持有期内调出沪深 300 不触发临时换仓；
- 长期停牌股票不进入新组合。

原文综合得分：

$$
Score_i = Percentile(ROE_i) + 1 - Percentile(PB_i)
$$

必须支持的分组：

- ROE 前 10、前 20、前 50、50-100、100-200、200 以后；
- PB 前 10、前 20、前 50、50-100、100-200、200 以后；
- PB-ROE 综合得分使用相同分组；
- 行业内综合得分前 5；行业不足 5 只时全部选择。

原文成本配置：初始建仓 0.6%，后续每次调仓 1.3%。该配置只用于原文对照，不用于现代层。

## 4. 现代回测口径

- 股票池：信号日有效的沪深 300 历史成分股（`CSI300`，主股票池）；
- 频率：月末；
- 信号：月末收盘后计算；
- 成交：下一交易日开盘；
- 持有：至下一次调仓；
- 剔除 ST、退市整理期、上市不足 120 个交易日和信号日不可交易股票；
- 成本：10bp、30bp、50bp 全包成本敏感性；
- 因子：截面 1%/99% winsorize 后标准化；
- 正式标签：下一持有期原始个股收益；现有行业为静态快照，不生成正式历史行业中性标签；
- 中证 800 和其他股票池不作为现代层实验；稳健性检验仅改变同一沪深 300 股票池内的时间窗口、成本、持仓数、行业处理或因子定义。

## 5. Point-in-time 不变量

1. 任意财务值必须满足 `effective_date <= signal_date`；
2. 更正记录仅从 `revision_date` 开始可用；
3. 指数成员必须满足 `member_from <= signal_date < member_to`；
4. 不允许用当前成分股回填历史股票池；
5. 不允许用未来数据填补因子缺失；
6. 预测收益期必须严格晚于信号期；
7. 任意训练或验证标签必须满足 `exit_date <= prediction signal_date`，未成熟标签必须隔离；
8. 组合入选股票不得根据未来 `forward_return` 是否缺失进行筛选；
9. 数据冲突时保留全部来源记录，由确定性优先级生成 canonical 记录。

## 6. 数据质量闸门

全量研究运行前必须满足：

- 核心表主键重复率为 0；
- 历史成分股覆盖率不低于 95%；
- 财务公告时点覆盖率不低于 95%；
- 行情 OHLC 逻辑错误率为 0；
- 复权收益绝对值超过 50% 的记录必须进入异常清单；
- 任一核心因子月度覆盖率低于 80% 时不得进入最终模型；
- 至少随机抽查 10 个股票-报告期并记录审计结果。

若 2005-2011 数据不满足闸门，原研报部分只能标为“逻辑复现”；现代样本从首个连续满足闸门的月份开始。

当前全量审计确定：现代数据仍从 2010-01 开始下载和积累，但 PB、ROE 同时连续达到 80% 覆盖率的首月为 2012-05-31，因此现代因子评价和模型样本从该月开始。AKShare/Eastmoney 历史批量财务接口返回最新公告日期；修订后的历史值只允许从该最新公告日开始生效，不回填到更早信号日。

## 7. 样本与统计

- 2010-2014：热身与历史特征积累；
- 2015-2022：研究开发；
- 2023-2025：冻结样本外；
- IC 使用 Spearman 相关；
- 报告 IC Mean、ICIR、正值比例和 Newey-West t 值；
- 分层必须同时报告全部层、单调性和 Top-Bottom；
- 绩效报告年化收益、波动、Sharpe、最大回撤、Calmar、换手和成本后收益。

## 8. 验收与停止条件

- smoke 数据集通过全部 PIT、因子方向、成交时点和组合权重测试后才能跑 full；
- 同一失败连续两次修复无效时停止重跑，先输出根因和最小复现；
- 结果文件必须包含配置哈希、数据指纹、代码版本和运行时间；
- 现场展示只读取冻结结果，不联网、不训练。
