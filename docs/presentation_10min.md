# PB-ROE复现与改进：10分钟演示讲稿

## 0:00–1:00 研究问题

目标不是只画出相似净值，而是回答两件事：2011年研报的PB-ROE策略在历史成分和可获得免费数据下能否复现；在严格PIT、成本和冻结样本外框架下，扩展因子与非线性模型是否真正改善结果。

## 1:00–2:20 复现设计

股票池使用每个调仓日有效的历史沪深300，不使用当前成分回填。原研报窗口为2005–2011年18次调仓；2005–2006缺失数据已增量补齐。财务值只在假定披露完成日以后生效，非交易日顺延到下一交易日。

展示：`docs/results/figures/paper-reproduction.svg`。

## 2:20–3:40 原研报复现结果

PB-ROE Top50成本后年化29.31%、累计净收益352.72%，原研报分别为35.00%和488.20%；18期中12期跑赢等权股票池，原研报为13期。方向和量级得到复现，但行业等权版本最优的结论没有复现。早期牛市窗口是旧版结果偏低的主要原因。

## 3:40–5:00 现代评价

现代实验使用2012-05至2025-10的月频PIT截面。BP Rank IC约4.56%，ROE约0.50%，PB-ROE综合得分约3.91%；PB-ROE统计显著，但30bp成本后多空年化只有2.28%，说明统计有效不等于可交易收益。

展示：`docs/results/figures/expanded-factor-ic.svg`。

## 5:00–6:30 改进方法

扩展到12个价值、质量、成长、动量、反转、波动和流动性因子。Elastic Net作为线性基准；LightGBM是唯一树模型。两者使用相同60个月滚动窗口，2023–2025冻结样本外不参与选因子和调参。

## 6:30–7:40 模型结果

Elastic Net整体IC 5.54%，冻结期6.06%；LightGBM整体4.28%，冻结期6.23%。LightGBM只在冻结期略高，开发期明显低于Elastic Net，不能仅凭冻结期单点结果宣称非线性胜出。

展示：`docs/results/figures/model-ic-comparison.svg`。

## 7:40–8:50 组合与成本

组合约束包括3%单票上限、行业偏离不超过5%、月换手不超过30%，协方差使用Ledoit-Wolf。冻结期30bp成本后，Elastic Net年化8.64%，LightGBM 9.39%，等权代理5.62%；但开发期两者均约-1.7%，冻结期超额主要来自2023年。

展示：`docs/results/figures/portfolio-net-value.svg`。

## 8:50–9:30 审计与局限

正式审计14/14通过，包括16项数据闸门、82,732条预测时间顺序、组合约束、离线展示和冻结区间。局限包括免费源不能逐值复刻Wind、早期ROE采用披露截止假设、基准权重使用成员等权代理、历史总市值缺失。

## 9:30–10:00 结论

第一，PB-ROE的价值质量方向和历史收益量级可以复现，但不能复现所有细节结论。第二，现代样本中BP与扩展因子有效，ROE单因子较弱。第三，LightGBM没有形成跨阶段稳健优势，因此项目的改进结论是“严格检验后有限增量”，而不是“复杂模型必然更好”。
