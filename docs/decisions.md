# 决策记录

## D001：双层研究口径

- 状态：已冻结
- 决策：原研报三次调仓复现与现代月频实验完全分离，使用不同配置和实验编号。
- 原因：月频、次日开盘和 BP 标准化属于改进，不能被表述为原文规则。

## D002：只保留一个树模型

- 状态：已冻结
- 决策：非线性模型只使用 LightGBM；线性基准使用 Elastic Net。
- 原因：LightGBM 与 XGBoost 同属梯度提升树，重复比较不如加强 PIT、样本外和解释性。

## D003：免费数据与结论强度

- 状态：已冻结
- 决策：免费数据优先；覆盖不足时缩短严格样本或标注逻辑复现，不伪造精确复刻。

## D004：冻结样本外

- 状态：已冻结
- 决策：2023-2025 不用于选择因子、模型和参数。

## D005：运行预算

- 状态：已冻结
- 决策：所有模块必须支持 smoke/full 模式；full 仅在数据闸门和相关测试通过后执行。

## D006：主股票池

- 状态：已冻结
- 决策：原研报复现与现代改进的主股票池统一使用调仓日有效的沪深 300 历史成分股（`CSI300`）；不使用中证 800 作为正式研究股票池。
- 原因：与原研报保持可比，控制小市值、流动性和行业结构变化带来的混杂；中证 500只在主结论冻结后作为独立稳健性扩展。
